BiliFluent 安装与更新指南
==============================================

BiliFluent 是采用 Fluent UI 与 WinUI 3 原生控件、专为 Windows 优化的第三方哔哩哔哩客户端。无广告，注重低资源占用与流畅播放。
基于 Richasy 的「哔哩助理」(Bili Copilot) 二次开发，遵循 GPL-3.0 协议。

下载地址：https://github.com/Better-Native-APPs/BiliFluent/releases
系统要求：Windows 10（Build 19041 及以上）或 Windows 11，x64。

=== 安装步骤（推荐）===

1. 下载最新的 BiliFluent-<版本>.zip 并完整解压。
2. 双击解压目录中的“安装 BiliFluent.cmd”。
3. 弹出 UAC 提权提示时选择【是】。
   脚本会自动核验包哈希，将公钥证书导入 LocalMachine\TrustedPeople（不导入 Root），随后安装应用。
4. 安装完成后，在「开始」菜单中启动 BiliFluent。

=== 手动安装（PowerShell）===

1. 在解压目录下打开 Windows PowerShell。
2. 只读预检：
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1
3. 正式安装：
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1 -Install

若手动导入证书，可在管理员 PowerShell 中运行：
Import-Certificate -FilePath .\payload\BiliFluent.cer -CertStoreLocation Cert:\LocalMachine\TrustedPeople
然后返回普通用户窗口执行 .\Install.ps1 -Install。

=== 更新与共存 ===

- 更新：下载新版本 ZIP 解压后运行安装脚本平滑升级。
- 共存：包标识独立（CN=BiliFluent），不覆盖官方应用或上游哔哩助理。
