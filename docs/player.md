# BiliFluent 播放体验

BiliFluent 采用 Fluent UI 与 WinUI 3 原生控件构建播放界面，专注流畅播放与低资源占用。

## 核心特性

- **mpv 内嵌省电弹幕**：默认启用基于 libass 的内嵌渲染，降低 CPU 与显存占用（保留 Win2D 备选）。
- **资源及时释放**：关闭播放窗口时即时完全释放 mpv 实例、解码句柄与显存。
- **进度合并刷新**：节流合并高频位置通知，进度拖拽更平稳。
- **WMP 风格全屏**：
  - 双击画面切换全屏。
  - 快捷键 `F` 或 `F11` 进入/退出全屏。
  - 快捷键 `Esc` 退出全屏返回普通窗口。
- **后台效率模式**：窗口最小化或后台空闲无播放任务时，自动调度 Windows 效率模式节省电量。
- **低配硬件预设**：
  - 默认自动画质上限为 1080P60，优先使用 AVC/H.264 硬件解码。
  - 默认 demuxer 缓存为 64 MiB。
  - 在「设置 → MPV 附加设置 → 内置配置切换」提供「快速 (Fast)」配置，专为入门核显减负。

## 播放后端

| 播放后端 | 特点 | 适用场景 |
| --- | --- | --- |
| **内置 MPV（推荐）** | 支持省电弹幕、D3D11 硬解、精确跳转与参数调节 | 推荐首选 |
| **原生播放器** | 使用系统内置 Media Player 核心 | 需要系统解码管线时 |
| **外部播放器** | 调用本地已安装的外部播放器（如 mpv、PotPlayer） | 自定义外部渲染器或脚本时 |
| **网页播放器** | 基于 WebView2 加载网页 | 排查兼容性时的备选方案 |

## 空降助手

内置空降助手（基于 SponsorBlock 协议），可识别视频片段标记：
- 自动或提示跳过合作广告、片头片尾与无意义片段。
- 在播放进度条上分色高亮精彩片段。
- 在「设置 → 空降助手」中自定义各分类的跳过策略。
