# 常见问题

## BiliFluent 是什么？
BiliFluent 是采用 Fluent UI 与 WinUI 3 原生控件、专为 Windows 优化的哔哩哔哩第三方桌面客户端。无广告，注重低资源占用与流畅播放。项目基于 Richasy 开源的「哔哩助理」([Bili Copilot](https://github.com/Richasy/Bili.Copilot)) 二次开发，遵循 GPL-3.0 协议。

## 如何安装与更新？是否会与官方客户端冲突？
- **独立共存**：包身份为 `BiliFluent` / `CN=BiliFluent`，不覆盖官方桌面客户端或原「哔哩助理」，配置互相独立。
- **安装**：从 [GitHub Releases](https://github.com/Better-Native-APPs/BiliFluent/releases) 下载 ZIP，解压后双击解压目录中的 `安装 BiliFluent.cmd`，UAC 确认后完成安装；或通过 PowerShell 执行 `Install.ps1 -Install`。
- **更新**：下载新版 ZIP 解压后运行安装脚本即可平滑升级。

## 低配设备和平板有哪些优化？
1. **mpv 内嵌省电弹幕**：降低 CPU 与显存占用。
2. **播放资源及时释放**：关闭视频窗口时即时完全释放 mpv 实例与显存。
3. **进度合并刷新**：节流合并高频位置通知，拖拽更顺畅。
4. **后台效率模式**：窗口最小化或后台空闲时自动进入 Windows 效率模式。
5. **64 MiB 默认缓存**：控制内存占用。
6. **自动 1080P60 上限与 H.264 优先**：确保大部分核显走硬件解码。
7. **一键「快速 (Fast)」预设**：在「设置 → MPV 附加设置」提供弱显卡配置切换。
8. **WMP 风格全屏**：支持双击画面或 `F` / `F11` / `Esc` 快捷切换。

## 播放卡顿、掉帧如何处理？
1. 在「设置 → 播放行为」确认弹幕引擎为「mpv 内嵌（省电）」。
2. 在「设置 → 播放控制」将编码偏好设置为「AVC/H.264」。
3. 在「设置 → MPV 附加设置」将「内置配置切换」改为「快速」。
4. 适当降低播放清晰度至 1080P 或以下。
5. 更新显卡驱动以确保硬解支持正常。

## 画面黑屏或异常怎么办？
1. 关闭播放窗口后重新打开。
2. 在「设置 → MPV 附加设置」切换视频输出显卡。
3. 若启用了自定义 `mpv.conf`，先关闭自定义配置排查。
4. 可在「播放行为」中尝试切换至其他播放后端对照。

## 没有大会员能播放大会员内容吗？
不能。清晰度上限与大会员专享权益由账号本身权限决定，应用不提供破解或绕过功能。

## 什么是空降助手？
内置基于 SponsorBlock 协议的片段跳过功能，支持自动或提示跳过合作广告、片头片尾与无意义片段，可在「设置 → 空降助手」中自定义策略。
