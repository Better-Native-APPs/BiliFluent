# 功能模块

BiliFluent 采用 Fluent UI 与 WinUI 3 原生控件，支持侧边导航折叠与宽度调节。

## 视频

- **推荐**：首页个性化视频流。
- **热门与排行榜**：全站与子分区热门榜单。
- **分区索引**：按分类浏览最新与精选视频。
- **搜索**：支持综合、视频、番剧、直播与用户多维度搜索。
- **个人收藏**：稍后再看、自定义收藏夹与历史记录。

## 直播

- **直播分区**：分类浏览在播内容。
- **原生播放**：支持清晰度切换与弹幕收发。

## 动漫与影视

- **番剧与国创**：按周更新日历与分类索引。
- **影视专区**：电影、电视剧、纪录片与综艺浏览。

## 动态与用户空间

- **动态**：浏览关注 UP 主的视频与图文动态。
- **用户空间**：查看 UP 主投稿、专栏、合集与关注列表。

## 专栏与文章

- **文章阅读器**：WinUI 原生图文排版，支持代码块高亮。
- **搜索联动**：划词支持快速搜索与复制。

## 消息与通知

- **消息列表**：查看系统通知、回复与收到的赞。
- **系统通知**：支持 Windows 原生消息提醒与跳转激活。
