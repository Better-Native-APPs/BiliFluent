# 账号登录

登录后可同步个人动态、历史观看进度与收藏夹。

## 登录方式

### 扫码登录（推荐）
1. 打开哔哩哔哩手机客户端，使用「扫一扫」扫描屏幕上的二维码。
2. 在手机端点击「确认登录」。
3. 二维码过期时点击刷新按钮重新获取。

### 网页登录
点击登录窗口底部的「网页登录」，在弹出的 Web 页面中完成账号登录与验证。

## 凭据安全

- **本地存储**：Token 与 Cookie 仅保存在当前 Windows 用户的应用私有数据目录中。
- **退出登录**：点击导航栏头像，在个人菜单中选择「退出登录」即可清除本地登录缓存。
