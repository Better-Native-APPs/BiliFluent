# 播放器自定义

可在设置中调整播放控制、行为偏好与 MPV 内核参数。

## 播放控制

路径：**「设置 → 播放控制」**

- **编码偏好**：支持 AVC/H.264、HEVC/H.265 与 AV1；默认 AVC/H.264 优先以保障硬件解码。
- **快进 / 后退秒数**：自定义单次跳进与后退的时长。
- **临时加速系数**：长按画面时的倍率乘数（默认 1.5 倍），松开恢复原倍速。
- **记忆播放倍率**：跨视频是否沿用上一视频的播放速度。
- **底部进度条**：隐藏控制栏时是否在窗口底部保留微型进度条。
- **全屏快捷操作**：
  - 双击画面切换全屏。
  - 快捷键 `F` 或 `F11` 进入/退出全屏。
  - 快捷键 `Esc` 退出全屏。

## 播放行为与弹幕引擎

路径：**「设置 → 播放行为」**

- **默认清晰度**：启动播放的首选清晰度；默认自动上限为 1080P60。
- **弹幕渲染引擎**：
  - **mpv 内嵌（省电，默认）**：基于 libass 内嵌渲染，降低 CPU 与显存占用。
  - **Win2D 原生渲染**：独立 Win2D 图层渲染，供兼容性对照。

## MPV 附加设置

路径：**「设置 → MPV 附加设置」**

- **内置配置切换（`--profile`）**：
  - **高质量**：默认配置。
  - **快速 (Fast)**：专为入门核显设计，降低着色器负荷。
- **最大缓冲大小（`--demuxer-max-bytes`）**：默认 64 MiB。
- **最大后向缓冲大小（`--demuxer-max-back-bytes`）**：回退缓存容量。
- **最大缓冲秒数（`--demuxer-readahead-secs`）**：预读时长（默认 60 秒）。
- **精确跳转（`--hr-seek`）**：控制拖拽进度时是否对齐关键帧。
- **音频独占（`--audio-exclusive`）**：独占音频直通声卡。
- **显卡输出适配器**：选择 D3D11（`--d3d11-adapter`）或 Vulkan（`--vulkan-device`）调用的显示芯片。
- **自定义配置**：开启「使用自定义 MPV 配置」后可点击「打开配置」编辑本地 `mpv.conf`。
