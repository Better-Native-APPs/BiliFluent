# 隐私与数据安全

BiliFluent 为开源无广告应用，尊重并保护用户隐私。

## 数据请求与传输

- **接口直连**：客户端直接向哔哩哔哩接口及其 CDN 发起请求，不设中转服务器，无数据埋点与广告追踪。
- **凭据存储**：登录 Token 与 Cookie 仅保存在当前 Windows 用户的应用私有数据目录中，绝不上传至任何第三方服务器。

## 本地日志与脱敏

- 错误日志保存在设置面板的「日志记录」目录中。
- 提交 Issue 反馈前，请人工检查并删除日志中的用户名、本地路径（如 `C:\Users\...`）、Cookie 与 Token 等信息。
- 排查问题无需提供代码签名私钥或密码。

## 拓展服务

- **空降助手**：启用时向公共 SponsorBlock 协议服务器查询片段信息，仅发送视频标识的前缀哈希，不包含账号信息。
