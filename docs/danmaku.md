# 弹幕体验

BiliFluent 提供两种弹幕渲染引擎，可在「设置 → 播放行为 → 弹幕渲染引擎」中切换：

- **mpv 内嵌（省电，默认）**：弹幕直接输入播放器内核渲染，降低 CPU 与显存占用，推荐在轻薄本与低配平板上保持开启。
- **Win2D 原生渲染（备选）**：基于 Win2D 画布图层渲染，供兼容性对照。

## 弹幕控制

在播放窗口控制栏中提供弹幕面板：
- **弹幕开关**：一键开启或隐藏弹幕。
- **显示区域**：支持全屏、半屏或顶部/底部区域覆盖。
- **外观调整**：调节不透明度与字体大小。
- **弹幕过滤**：独立屏蔽滚动、顶部固定或底部固定弹幕。

## 排障

1. **未显示弹幕**：检查右下角弹幕开关是否开启，或尝试重新打开。
2. **高密度弹幕掉帧**：
   - 确认引擎为「mpv 内嵌（省电）」。
   - 在弹幕面板中将显示区域调整为「半屏」。
   - 在「设置 → 播放控制」中确认编码为「AVC/H.264」。
   - 在「设置 → MPV 附加设置」中切换配置为「快速 (Fast)」。
